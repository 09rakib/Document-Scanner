the normal entry point using `flutter run -d <android-device-id>`.

## Assumptions and remaining phases

IDs are generated by SQLite. Timestamps are stored in UTC milliseconds. Reads
are newest-first, with IDs breaking timestamp ties. Search supports English
ASCII case-insensitivity and Bangla substrings; names are not linguistically
collated. Metadata delete intentionally does not delete files. Phase 2/3 must
coordinate managed file cleanup with metadata changes and invalidate providers
after successful writes.

No user configuration is needed for Phase 1. Scan integration, PDF storage and
visible list/actions remain for Phases 2/3. No ads or purchases were added.
